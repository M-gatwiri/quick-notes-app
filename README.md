# QuickNotes

## Project Description

QuickNotes is a simple web application that allows users to create, organise, search, and delete personal notes. Users can assign categories to their notes, including Personal, Work, and Study. The application uses browser local storage to keep notes saved even after the page is refreshed.

## Features

* Add notes with a selected category.
* Organise notes into Personal, Work, and Study categories.
* Validate notes to prevent empty entries and notes longer than 200 characters.
* Delete individual notes.
* Display the total number of saved notes.
* Search notes by keywords.
* Save notes using browser local storage.
* Display the date and time each note was created.
* Reset the note form after successfully adding a note.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* Git and GitHub

## How to Run the Project Locally

1. Clone or download this repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.
5. Start adding and managing your notes.

No additional installation is required.
